# 🗂️ Git Mastery Showcase

A hands-on Git learning repo built around a real (fake) project — a **Todo app called Taskly**.

Every Git concept is demonstrated through actual Taskly development scenarios:
adding features, fixing bugs, handling conflicts, and managing releases.
The commit history itself is part of the showcase — read the messages.

---

## 📁 Structure

| Folder | Concept | Taskly scenario |
|--------|---------|-----------------|
| [`01-basics/`](./01-basics/) | Init, stage, commit, push/pull | Setting up Taskly from scratch |
| [`02-branching/`](./02-branching/) | Branches, merge, rebase | Building features in parallel |
| [`03-conflicts/`](./03-conflicts/) | Merge conflicts + resolution | Two devs editing the same file |
| [`04-advanced/`](./04-advanced/) | Stash, cherry-pick, tags, reflog | Real workflow interruptions |

---

## 🗂️ Concepts covered

- [x] `git init`, `add`, `commit`, `status`, `log`
- [x] `git push`, `pull`, `fetch`, `clone`
- [x] Feature branches + `git merge` (fast-forward & --no-ff)
- [x] `git rebase` vs merge
- [x] Merge conflict creation + resolution
- [x] `git stash` + `git stash pop`
- [x] `git cherry-pick`
- [x] `git tag` (lightweight + annotated)
- [x] `git reflog` — recovering lost commits

---

## 💡 Why this exists

Learning Git from docs is one thing — using it on a real codebase is another.
This repo is a living record of that practice, built around one consistent project
so every concept connects to something tangible.
